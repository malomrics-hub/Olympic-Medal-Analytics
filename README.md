#  Olympic Medal Analytics | Power BI Dashboard

##  Project Overview

This project presents an interactive Olympic Medal Analytics Dashboard developed using Microsoft Power BI.

The dashboard explores historical Olympic Games data to analyze medal distributions, athlete performance, and trends across different Olympic editions.

The main objective is to transform raw data into meaningful visualizations that enable users to explore Olympic performance through an interactive and user-friendly dashboard.

##  Project Objectives

- Analyze the distribution of gold, silver, and bronze medals.
- Explore medal trends across Olympic editions.
- Compare athlete and country performance.
- Identify patterns in historical Olympic results.
- Create an interactive dashboard for effective data exploration.

##  Tools & Technologies

- **Power BI Desktop** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Creating measures and analytical calculations.
- **Data Modeling** – Organizing data for effective analysis.

##  Dashboard Features

### Medal Analysis
- Gold, silver, and bronze medal KPIs.
- Medal distribution visualizations.
- Medal trends across Olympic editions.

### Athlete Analysis
- Athlete performance analysis.
- Insights into medal-winning athletes.
- Youngest medal-winning athlete analysis.

### Interactive Features
- Dynamic slicers and filters.
- Interactive charts with cross-filtering.
- Reset Filters button.
- KPI cards and visual comparisons.

##  Data Preparation

The project includes data preparation and analytical modeling to support accurate reporting.

Medal-related calculations distinguish gold, silver, and bronze medal records from missing medal values.
